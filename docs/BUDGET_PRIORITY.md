# 概算优先补查
默认 cross_validation.yaml mode: prefer_budget。所有映射编码进入覆盖报告，剔除通用、资源章节、表格与非量化字段；原始概算表全量索引复用。精确字段名称、可信字段规则和设备价格目录提供候选；同口径同单位且多个可信候选一致才补值或替换。不存在可靠候选、概算表互相冲突、口径或单位不清、派生关系或多行组合表歧义时保留原值并记录原因。未实现对所有字段的专属等价行匹配，也不做自动求和。details.crossValidation.fields[].adoption 记录采用前值、映射值、来源、采用后值和支持证据；fieldIndex 以及 result/mapped 同步，单行组合表同步。audit 模式可恢复只审计。正式输出前重新执行映射一致性校验。旧算子顺序不变。真实报告仍需回归。
