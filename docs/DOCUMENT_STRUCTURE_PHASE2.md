# 文档结构优先改造（兼容阶段）

- 预抽取阶段沿用同一 AST，结构识别和章节识别后生成只读结构索引。无需重复读取文档。
- configs/document_structure.yaml 是标题样式、表题关键词、题注正则、章节反向匹配规则的配置来源。生产工厂按 config_root 加载并校验；直接构造解析器使用仓库默认配置。
- details.json 新增 documentStructure，包含章节节点及父子关系、原始块顺序、物理表 ID/行宽/标题候选、来源位置（加载器能提供时）、异常诊断。include_text=true 可输出原始块与单元格；默认关闭以控制文件大小。
- diagnostics.mode: audit（默认）、strict（仅结构错误中止）、off。无标题、缺表题、行宽不齐只提示，不判定业务值错误。
- Aspose 采集原始合并标记，不改变现有表格矩阵。尚未恢复实际合并跨度、多级表头和跨页逻辑表。扫描 PDF 正文 OCR 未实现。
- enhanced_styles 和 toc_exclusion 默认关闭，允许针对新样式启用并回归。保持旧标题匹配顺序和表题章节优先级。
- 不调整现有字段、专业抽取与映射。此阶段不是全量 YAML 迁移，也不代表所有报告结构正确。后续需用真实报告结构金标准验证后逐步启用增强模式；再统一逻辑表与候选协议，接入概算复核。

## 续表与表格元数据补充

保留 Word XML gridSpan/vMerge/hMerge 和声明表头行、Aspose 声明表头，以及现有 PDF 续表合并的原始片段 ID、页码和行位置。快照新增 logicalTables，能够区分已有 PDF 续表合并的物理来源与逻辑表，不改变原矩阵或原匹配算法。Word 续表统一恢复、多级表头展开仍待验证和实施。
